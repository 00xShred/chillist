# chillist

just a chill, text-based launcher widget for android. replaces your cluttered app grid with a clean list of apps.

![preview](example.png)

## features

- text list to launch apps
- custom labels to rename them
- themes like catppuccin, gruvbox, nord, and tokyo night
- adjust fonts, sizes, and alignment
- optional date/time, search, and dividers

## build

1. clone the repo:
   `git clone https://codeberg.org/gabriel/chillist.git`
2. run `./gradlew installDebug`
3. add the widget to your home screen
